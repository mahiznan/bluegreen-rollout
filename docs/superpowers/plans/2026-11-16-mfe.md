# Phase 10: Vite MFE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a React + Vite page (`services/mfe`) that is released, bound, flipped and retired with the same scripts as the other services, and can be tested in a real browser.

**Architecture:** A multi-stage image (Node builds with `vite build`, `nginx-unprivileged` serves `dist/`). The gateway URL and the commit are baked in at build time as `VITE_GATEWAY_URL` and `VITE_COMMIT`. `release.sh` learns per-service build args and a service without a ConfigMap; `status.sh` learns the `mfe` rows. The page calls the single gateway; the browser sets `Origin`.

**Tech Stack:** React 19, Vite 6, Node 22 (build image), `node:test` for the one pure module, nginxinc/nginx-unprivileged 1.27-alpine, bash.

## Global Constraints

- Release id is the last commit touching `services/mfe`; `release.sh` refuses a dirty `services/mfe`.
- Objects are named `mfe-<commit>`; no v1/v2; no blue/green names.
- 1 pod per release; requests at most `cpu: 20m`, `memory: 32Mi` (CRC node memory is about 92% allocated).
- Gateway URL is baked in at build time (`VITE_GATEWAY_URL`); no runtime config.
- The page never sets `Origin`; it sends `Idempotency-Key`, `X-User-Group`, `Content-Type` only (these are the headers the gateway CORS allows).
- The user runs state-changing `oc` commands themselves and commits each phase; use `git commit services/<dir> -m ...`, never `git commit -am`.
- Commands for the user use HTTPie `http`, not curl.
- Project guard: scripts run only in OpenShift project `bluegreen`.

```js
// Pure helpers for calling the gateway. No React, no import.meta.env, so node:test can run it.
export const GROUPS = ['pilot', 'standard'];

export function newIdempotencyKey(now = Date.now(), rand = Math.random) {
  return `mfe-${now}-${Math.floor(rand() * 1e6)}`;
}

export function buildRequest({ gateway, group, key, form }) {
  return {
    url: `${gateway.replace(/\/+$/, '')}/api/v1/payments/authorize`,
    options: {
      method: 'POST',
      // Only headers the gateway's CORS allows. The browser adds Origin itself; the page must not.
      headers: {
        'Content-Type': 'application/json',
        'Idempotency-Key': key,
        'X-User-Group': group,
      },
      body: JSON.stringify({
        orderId: form.orderId,
        amount: Number(form.amount),
        currency: form.currency,
        cardToken: form.cardToken,
      }),
    },
  };
}

export async function authorize(args, fetchImpl = fetch) {
  const { url, options } = buildRequest(args);
  let res;
  try {
    res = await fetchImpl(url, options);
  } catch (e) {
    return {
      kind: 'network',
      message: `network or CORS error (${e.message}). Open DevTools, Network and Console, to see which.`,
    };
  }
  const text = await res.text();
  let body = null;
  try { body = JSON.parse(text); } catch { /* not JSON, keep the text */ }
  if (res.ok) return { kind: 'ok', status: res.status, body };
  return { kind: 'http', status: res.status, body, text };
}
```

`services/mfe/src/App.jsx`:

```jsx
import { useState } from 'react';
import { authorize, newIdempotencyKey, GROUPS } from './api.js';
import { config } from './config.js';
import { RELEASE_NOTE } from './release-note.js';

export default function App() {
  const [form, setForm] = useState({ orderId: 'o-1', amount: '250', currency: 'USD', cardToken: 'tok_demo' });
  const [group, setGroup] = useState('pilot');
  const [result, setResult] = useState(null);
  const [busy, setBusy] = useState(false);

  const set = (name) => (e) => setForm({ ...form, [name]: e.target.value });

  async function submit(e) {
    e.preventDefault();
    setBusy(true);
    setResult(await authorize({ gateway: config.gateway, group, key: newIdempotencyKey(), form }));
    setBusy(false);
  }

  const served = result && result.kind === 'ok' && result.body ? result.body.served : null;

  return (
    <main>
      <header className="banner">
        <strong>mfe {config.commit}</strong>
        <span>page origin: {window.location.origin}</span>
        <span>gateway: {config.gateway}</span>
        <span>note: {RELEASE_NOTE}</span>
      </header>

      <form onSubmit={submit}>
        <label>Order id <input value={form.orderId} onChange={set('orderId')} /></label>
        <label>Amount <input value={form.amount} onChange={set('amount')} inputMode="decimal" /></label>
        <label>Currency <input value={form.currency} onChange={set('currency')} /></label>
        <label>Card token (fake) <input value={form.cardToken} onChange={set('cardToken')} /></label>
        <label>User group (stands in for the JWT claim)
          <select value={group} onChange={(e) => setGroup(e.target.value)}>
            {GROUPS.map((g) => <option key={g}>{g}</option>)}
          </select>
        </label>
        <button disabled={busy}>{busy ? 'Authorizing...' : 'Authorize'}</button>
      </form>

      {result && result.kind === 'ok' && (
        <section className="ok">
          <h2>{result.body?.status} (HTTP {result.status})</h2>
          <p>risk: {result.body?.risk?.decision} (score {result.body?.risk?.score})</p>
          {served && (
            <table>
              <tbody>
                <tr><th>eAPI</th><td>{served.eapi.commit}</td><td>{served.eapi.pod}</td></tr>
                <tr><th>domain</th><td>{served.domain.commit}</td><td>{served.domain.pod}</td></tr>
              </tbody>
            </table>
          )}
          <details><summary>raw response</summary><pre>{JSON.stringify(result.body, null, 2)}</pre></details>
        </section>
      )}
      {result && result.kind === 'http' && (
        <section className="error">
          <h2>HTTP {result.status}</h2>
          <pre>{result.body ? JSON.stringify(result.body, null, 2) : result.text}</pre>
        </section>
      )}
      {result && result.kind === 'network' && (
        <section className="error"><h2>No answer</h2><p>{result.message}</p></section>
      )}
    </main>
  );
}
```
